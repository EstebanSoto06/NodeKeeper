# NodeKeeper · Frontend

SPA React + Vite + Tailwind (Design System "liquid glass") del sistema NodeKeeper para Coopelesca. Consume la API real del backend; ya no depende de datos mock.

Para instalación, variables de entorno, comandos y arquitectura, ver la documentación del repositorio raíz:

- [README.md](../README.md) — visión general, instalación rápida, comandos.
- [docs/LOCAL_SETUP.md](../docs/LOCAL_SETUP.md) — guía paso a paso de arranque local.
- [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) — arquitectura y módulos.
- [docs/TESTING.md](../docs/TESTING.md) — pruebas y cobertura del frontend.

## Comandos propios de este paquete

```bash
npm install
npm run dev            # http://localhost:5173
npm run build
npm run test
npm run test:coverage
```
